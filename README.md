# Data Cleaning and Visualization Project

## Project Overview

This project demonstrates the process of cleaning a sales dataset and creating meaningful visualizations using Microsoft Excel. The project includes data cleaning, Pivot Tables, charts, and an interactive dashboard to analyze sales performance.

## Objectives

* Learn data cleaning techniques
* Handle missing values and duplicate records
* Perform data transformation and formatting
* Create Pivot Tables and charts
* Build an interactive dashboard
* Publish the project using GitHub

## Tools Used

* Microsoft Excel
* GitHub

## Dataset

The dataset contains sales transaction information including:

* Date
* Product
* Category
* Units
* Price
* Amount

## Data Cleaning Tasks Performed

* Removed duplicate records
* Checked and handled missing values
* Standardized data formatting
* Validated data consistency
* Prepared the dataset for analysis

## Data Analysis

Pivot Tables were created to summarize the dataset and identify important business insights.

## Dashboard

The dashboard includes visualizations such as:

* Sales Summary
* Pivot Charts
* Category-wise Analysis
* Interactive Excel Dashboard

## Project Deliverables

* Cleaned Excel Dataset
* Pivot Tables
* Dashboard
* Data Cleaning Report
